# 키캡 클릭커

`index.html`을 브라우저에서 열면 실행됩니다. 설치와 서버가 필요하지 않습니다.

키캡은 한 번 누른 뒤 5초의 공통 쿨타임이 적용됩니다. 마우스·터치·키보드를 번갈아 사용해도 쿨타임 중에는 추가 코인과 누름 소리가 발생하지 않습니다. 키캡 아래의 짧은 막대로 대기 시간을 표시합니다.

검은 바닥에 세라믹 느낌의 키캡 하나를 배치한 게임 기초입니다. 마우스, 터치, 스페이스바, 엔터로 누를 수 있고 눌림 애니메이션과 합성 타건음이 있습니다. 한 번 누를 때마다 1코인을 얻고 화면 상단에 잔액을 표시합니다. 길게 누르는 동안에는 추가 지급하지 않습니다. 코인은 획득할 때마다 브라우저에 자동 저장되며, 같은 브라우저에서 같은 주소로 다시 열면 복원됩니다. 브라우저 데이터를 삭제하면 저장된 코인도 지워집니다. 저장소 사용이 차단된 환경에서는 현재 실행 중에만 코인이 유지됩니다. 타건음은 연속 입력 시 겹쳐 재생되며 끝부분이 부드럽게 잦아듭니다.

- `index.html`: 화면과 SVG 키캡
- `style.css`: 배경, 크기, 눌림 효과
- `game.js`: 입력, 클릭 수, 타건음
- `store.js`: 코인, 상점 교체, 구매 및 인벤토리 저장

하단의 **상점**에서 30~150코인으로 6종의 추가 타건음을 구매할 수 있습니다. 매번 3종을 판매하며 5분마다 최소 한 상품이 바뀝니다. 미리듣기는 무료입니다. 구매한 소리는 **인벤토리**에서 장착할 수 있고, 기본 세라믹 소리로 돌아갈 수도 있습니다. 코인과 보유 소리, 장착 상태, 상점 상품 및 교체 시각은 함께 자동 저장됩니다. 기존 코인 저장 데이터도 자동으로 가져옵니다.

상점 로직 검증: `node --test store.test.cjs`

상점과 인벤토리의 **스킨** 탭에서 로즈 밀크, 민트, 오션 블루, 라벤더, 샴페인 골드, 미드나이트 키캡을 구매·장착할 수 있습니다(60~180코인). 색상 미리보기가 제공되며 5분마다 스킨 3종의 판매 구성이 바뀝니다. 스킨과 소리는 독립적으로 장착되고 자동 저장됩니다. 기본 아이보리 스킨은 무료로 보유합니다.

하단 볼륨 슬라이더로 모든 타건음과 미리듣기의 크기를 0~100%로 조절할 수 있습니다. 음소거 버튼은 기존 볼륨을 유지하며 소리를 끄고 켭니다. 슬라이더를 움직이면 음소거가 해제됩니다. 볼륨과 음소거 상태는 브라우저에 자동 저장됩니다.

외부 라이브러리, 이미지, 폰트 또는 네트워크 연결을 사용하지 않습니다.
