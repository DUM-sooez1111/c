# 키캡 클릭커

`index.html`을 브라우저에서 열면 실행됩니다. 설치와 서버가 필요하지 않습니다.

검은 바닥에 세라믹 느낌의 키캡 하나를 배치한 게임 기초입니다. 마우스, 터치, 스페이스바, 엔터로 누를 수 있고 눌림 애니메이션과 합성 타건음이 있습니다. 한 번 누를 때마다 1코인을 얻고 화면 상단에 잔액을 표시합니다. 길게 누르는 동안에는 추가 지급하지 않습니다. 코인은 실행 중 메모리에만 보관하며 새로고침하면 초기화됩니다. 타건음은 연속 입력 시 겹쳐 재생되며 끝부분이 부드럽게 잦아듭니다.

- `index.html`: 화면과 SVG 키캡
- `style.css`: 배경, 크기, 눌림 효과
- `game.js`: 입력, 클릭 수, 타건음

외부 라이브러리, 이미지, 폰트 또는 네트워크 연결을 사용하지 않습니다.
